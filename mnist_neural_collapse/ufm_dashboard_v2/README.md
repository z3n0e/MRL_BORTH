# MRL-UFM Nested Neural Collapse Dashboard v2

Open `index.html` in a browser. The site is fully static and uses local files only.

Contents:
- `index.html`: main page
- `style.css`: layout and dashboard styling
- `app.js`: all interactive logic
- `data.js`: embedded CSV/NPY-derived metrics and metadata
- `assets/`: all PNG plots copied from the original experiment outputs

Major sections:
1. Overview and method map
2. Final geometry dashboard
3. Animated training playback
4. Coordinate block usage
5. Gram matrix explorer
6. Original generated plot gallery
7. Raw metric/config tables
